# אני יצרתי את הבוט הזה - אני החלטתי לשתף אתכם

זה בוט ישן, אם אתם רוצים גרסא יותר מעודכנת וחדשנית שנוצרה במיוחד לפייבאם ישראל (לעולם לא פורסמה) כנסו ל[V2](https://github.com/TickerDev/fivem-israel-v2)

התקנה:
התקינו את כל החבילות הדרושות

```bash
    $ npm i
```

שנו את הקונפיג ב config.js / config.json לטעמכם

כדי להריץ:

```bash
    $ npm run watch
```

או

```bash
    $ npm start
```

תהנו ותזכרו - ואהבת לרעך כמוך, התנהגו לאחרים כמו שאתם רוצים שיתנהגו אליכם
